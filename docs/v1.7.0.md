# V1.7.0 — Declarative workflows and local progression

V1.7.0 adds declarative agents, workflows, persistent run snapshots, read-only status and inspection, and explicit local progression with `workflow resume` and `workflow complete-step`. `--latest` selects the newest valid run, including numeric suffix ordering.

An explicit pending result is limited to 256 KiB. Completion publishes it as completed and copies it literally into the next input, whose maximum size is 512 KiB. No Markdown or shell syntax is interpreted.

Multi-file changes are prepared and validated before publication. Same-directory `mv` makes each file replacement atomic on a conforming POSIX filesystem; the overall transition is protected by logical backups and rollback, but is not a filesystem-wide atomic transaction. Fail points exist only for tests.

Config reports run counts without exposing Markdown. Doctor validates run states, timestamps, results, transmissions, symlinks, and transaction residue; strict mode fails on warnings.

There is no C2-to-C3 migration. VERSION remains 1.7.0. Progression itself executes no provider, and no automatic Git operation, permission sandbox, or stored-content execution is introduced.

V1.7.0-D1 adds opt-in execution of one resumed step against the fixed local Ollama API. Only the persistent run snapshot is sent; prompt and response limits are enforced, output remains inert data, and `complete-step` is still required separately. Remote providers, automatic retries, loops, project scanning, shell execution, and Git automation remain unavailable.

V1.7.0-D2 adds the bounded `workflow run` sequential loop. It reuses the C3 transition and D1 execution operations, checkpoints bounded metadata in `orchestration.conf`, and protects the loop with a distinct lock. It stops on the first error, never retries or double-executes a successful step, and resumes from the persistent run. Parallelism, remote providers, project-source changes, and Git automation remain unavailable; VERSION is still 1.7.0 and no migration is required.
