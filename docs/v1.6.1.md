# CCB 1.6.1

V1.6.1-A adds declarative project skills through `.ccb/skills.conf`, with Ponytail modes `off`, `lite`, `full`, and `ultra`. New projects default to enabled `full`; `ccb skills` prints portable or optional agent-specific guidance without installing anything. Bootstrap now manages five files with CREATE/SKIP/CONFLICT and atomic per-file writes. Config and doctor parse skills safely; V1.6.0 projects remain compatible but are not migrated automatically.
