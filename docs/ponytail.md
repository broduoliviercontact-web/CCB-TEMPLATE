# Ponytail attribution

CCB adapts a short, portable set of project rules inspired by [Ponytail](https://github.com/DietrichGebert/ponytail), Copyright its authors and contributors, licensed under MIT. Source: `DietrichGebert/ponytail`.

CCB does not bundle Ponytail’s plugin, hooks, assets, package, or benchmark code. The `AGENTS.md` rules work without an external plugin. Any displayed plugin installation command is informational and must be reviewed and run manually by the user.
