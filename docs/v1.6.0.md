# CCB 1.6.0

V1.6.0-A added a minimal project bootstrap. V1.6.0-B made it idempotent with
`CREATE`, `SKIP`, `CONFLICT`, temporary-file preparation, and atomic per-file
renames. V1.6.0-C added declarative `generic`, `web`, `node`, `python`, and
`audio` profiles plus Ollama model routing and `ccb config`. V1.6.0-D adds the
non-mutating `ccb doctor` command, stronger validation, and CI coverage.

The four managed bootstrap files are `.ccb/project.conf`, `.ccb/models.conf`,
`.ccb/context/project.md`, and `AGENTS.md`. Init uses no network and doctor
makes no project change. The supported runtime provider is Ollama. Bootstrap
and doctor are POSIX-sh compatible on macOS and Linux; `--strict` makes doctor
warnings fail CI. Bootstrap’s multi-file finalization remains best-effort rather
than a perfect filesystem transaction.
