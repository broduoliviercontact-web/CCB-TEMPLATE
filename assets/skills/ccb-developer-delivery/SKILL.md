# Developer delivery

1. Confirm the approved scope and inspect relevant existing conventions.
2. Make the smallest maintainable change that meets the acceptance criteria.
3. Add or adjust focused tests when behaviour changes.
4. Run relevant checks and report files changed, results and remaining limitations.

Do not push, deploy or change Git history without explicit approval.
